# overrides

Your customisation lives here. Anything in this folder wins over the active theme and over package defaults.

Lookup order: `overrides/` then `themes/<active>/` then the package default.

To replace a file, mirror its path. Example: `overrides/themes/default/partials/product-card.ts` replaces the default product card.

The override resolver is part of the prototype roadmap (PR 12) and is not built yet.
